# Revo Advertising – Official Website

Revo Advertising is a digital-marketing, media, and advertising agency based in Morocco, helping brands grow through impactful digital strategies and creative media solutions.  
This repository contains the source code for the agency’s official website, built with **React** and hosted on **Vercel**.

---

## ✨ Features
- Fully responsive modern design
- Service overview: digital strategy, media buying, branding, production & advertising
- Clean and optimized React architecture
- Fast deployment and global CDN via Vercel
- SEO-friendly structure
- Easy to extend for new pages, languages, or features

---
